# GACOR (Gadai Cepat Cair) 

GACOR adalah aplikasi berbasis web untuk layanan gadai online yang cepat, aman, dan fleksibel dengan fitur-fitur unik.

## Fitur Unik
1. **Gadai Jemput**: Petugas kami menjemput barang jaminan langsung ke lokasi Anda.
2. **Gadai Delivery**: Pengiriman dana cepat dan pengembalian barang yang aman.
3. **Gadai Jual Online**: Opsi konversi gadai menjadi penjualan online jika tidak ditebus.

## Syarat Sistem
- PHP (v7.4 atau versi terbaru)
- MySQL / MariaDB (XAMPP / Laragon)
- Web Browser

## Panduan Instalasi & Penggunaan
1. **Clone / Download** repository ini ke folder lokal web server Anda (misal `htdocs/gacor`).
2. Buat database baru di phpMyAdmin dengan nama `gacor_db`.
3. Import file `gacor.sql` yang tersedia di dalam folder project ke database `gacor_db`.
4. Jalankan Apache dan MySQL melalui XAMPP Control Panel.
5. Buka browser dan akses URL: `http://localhost/gacor/`
